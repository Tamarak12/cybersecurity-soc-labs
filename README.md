# Cybersecurity & SOC Labs

Academic cybersecurity projects completed as part of my B.Sc. in Computer Science at HIT, in collaboration with a fellow student.

## SOC Threat Detection & MITRE ATT&CK
Analysis of security logs and rule-based alerts for Brute Force (T1110) and Network Service Discovery (T1046), including detection thresholds, source-IP grouping, and false-positive analysis.

## Login Anomaly Detection
Comparison of Isolation Forest and Autoencoder results for suspicious login detection using Python, with evaluation of precision, recall, F1 score, and false positives from a SOC perspective.

## Human-Guided AI Analysis in an Agentic SOC
Investigation of a high-risk security alert in a lab environment using Docker, Kafka/Redpanda, and Streamlit, including review of AI-generated evidence, false positives, and human-in-the-loop response decisions.

## Technologies & Concepts
Python • Docker • MITRE ATT&CK • Security Log Analysis • Threat Detection • Anomaly Detection • Kafka/Redpanda • Streamlit
